## 📊 Atomic Composition

The total number of atoms in this formula is calculated by finding the sum of the arithmetic series from 1 to 118:

$$\text{Total Atoms} = \sum_{k=1}^{118} k = \frac{118 \times 119}{2} = \mathbf{7,021 \text{ atoms}}$$
